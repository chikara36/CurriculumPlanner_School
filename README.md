# 教育課程編成支援 School v1.0.0

学校単独で利用する PWA 版です。教育委員会向け管理画面・中央DBは含みません。

## 主な機能

- 学校基本情報、教育目標、指導の重点
- 年間カレンダー
  - 日本の国民の祝日を内蔵ルールで自動反映
  - 学校独自休業日、振替休業日、土曜授業日、特別授業日
  - 学期始終日から年間授業日数を自動計算
- 年間計画時数から授業週数・週コマ数を自動算出
  - 1〜3週サイクル
  - 週28・29コマ等へ柔軟に対応
  - 生徒の中抜けを避け、空きコマを日末側に配置
- 授業時数、総合・学校行事、校時表
- 時間割データ
  - 学級、教員、教室・施設、授業
  - TT、合同、選択・展開、同時展開グループ
  - 教員未定・施設未定の仮設定
  - CSV一括入出力
- スマート時間割編成
  - 制約の多い授業を優先する独自ヒューリスティック
  - 複数回探索、限定的な再配置
  - 手動ドラッグ＆ドロップ
  - 固定、Undo / Redo
- 制約
  - 教員・学級・施設の重複禁止
  - 教員の授業不可時間、半休・全休、1日上限
  - 連続授業上限を SOFT / HARD 選択
  - 指定時間帯の休憩確保を SOFT / HARD 選択
  - 体育館・理科室等の同時利用上限
  - 授業固有の配置不可時間
- 欠勤・臨時時間割
  - 欠勤教員の影響授業を抽出
  - 授業交換、教科担当代替、自習・課題対応候補を組み合わせた複数案
  - 基本時間割を変更せず臨時時間割として保存
  - 行事・短縮日課の時限休止、後続時限の前詰め
- 最終チェック
- 帳票
  - 教育課程編成概要
  - 年間カレンダー
  - 授業時数配当表
  - 学級・教員・施設時間割
- IndexedDB 自動保存
- JSONバックアップ / 復元
- Google Drive 保存 / 読込（任意）

## PWAとして利用する

PWAのService Workerは、`file://` でHTMLを直接開く方式では動作しません。HTTPSで静的配信してください。

利用例:

1. 本フォルダ一式を、自治体・学校が管理するHTTPS対応Webサーバー、Vercel、Cloudflare Pages、GitHub Pages等へ配置する。
2. Chrome / ChromeOS でURLを開く。
3. 「PWAをインストール」またはChromeのインストール操作を行う。
4. 一度読み込んだ後は、主要機能をオフラインでも利用可能。

学校データを外部クラウドへ置けない場合は、学校・自治体のセキュリティ方針に適合する配信環境を使用してください。

## Google Drive 同期

Drive連携は任意です。コア機能はDriveなしで利用できます。

必要な設定:

1. Google Cloudプロジェクトを作成。
2. Google Drive APIを有効化。
3. OAuth同意画面を設定。Google Workspace環境では組織内アプリとしての運用を推奨。
4. OAuth Client ID を「Web application」で作成。
5. PWAの配信元URLを Authorized JavaScript origins に登録。
6. アプリの「Drive」画面で Client ID を入力。

使用スコープは `https://www.googleapis.com/auth/drive.file` です。アプリが作成・利用するファイルを中心に扱う設計です。

## 保存の考え方

- 正本: 学校単独版では端末の IndexedDB
- Drive: バックアップ / 端末移行
- JSON: 手動バックアップ

複数端末から同時編集する共同編集アプリではありません。同一学校で複数端末から編集する場合は、Driveから読み込む前に最新バックアップを確認してください。

## 知的財産上の方針

時間割編成は一般的な制約充足問題として独自実装しています。他社製品の画面、ソースコード、内部ファイル形式、固有名称、非公開アルゴリズムの複製を意図していません。

## 本番導入前に確認すべき事項

- 学校・自治体の情報セキュリティポリシー
- Google Workspace / OAuthアプリの許可設定
- 年度ごとの学習指導要領・標準授業時数等の制度マスター
- 祝日法改正・特例休日。内蔵祝日ルールは学校側の例外登録で補正可能
- 実データを使った時間割成立性テスト
- ブラウザ更新時の回帰テスト
- 個人情報を入力する場合の保存・端末管理方針
